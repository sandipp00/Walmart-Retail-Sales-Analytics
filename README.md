# Walmart Retail Sales Analytics & Demand Forecasting

End-to-end Walmart retail analytics using Python, SQL, Power BI, and machine learning.

## Dataset
- 6,435 rows
- 45 stores
- 2010-02-05 to 2012-10-26
- No missing values

## Objectives
- Data cleaning and validation
- Exploratory and statistical analysis
- Store and seasonal performance analysis
- Holiday and economic-variable analysis
- SQL business analysis
- Time-aware machine-learning prediction
- Time-series forecasting
- Power BI dashboard
- Streamlit analytics app

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Statsmodels, MySQL, Power BI, DAX, Streamlit, Plotly.

## Run
```bash
python -m venv .venv
pip install -r requirements.txt
python src/data_cleaning.py
python src/analysis.py
python src/train_model.py
streamlit run app/app.py
```
